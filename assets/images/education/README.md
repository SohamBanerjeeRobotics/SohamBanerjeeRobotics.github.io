# Education photos

Drop photos of the schools / colleges here. The Education cards on the home
page (`index.html`, `#timeline` section) look for these exact filenames and
show the image automatically — until a file exists, the card shows a
"Photo coming soon" placeholder.

| File                     | Card                                   |
| ------------------------ | -------------------------------------- |
| `iit-bombay.jpg`         | M.Tech — IIT Bombay                    |
| `iiest-shibpur.jpg`      | B.Tech — IIEST Shibpur                 |
| `kagram-highschool.jpg`  | Intermediate & Matriculation — Kagram A.N.M High School |

Recommended: landscape crop, ~1200×750 (16:10), JPG or WebP, under ~300 KB each.
If you use a different filename or format, update the `<img src>` values in
`index.html` to match.
